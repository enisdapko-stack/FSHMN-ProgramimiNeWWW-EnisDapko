# Java I — Pasaporta digjitale dhe GitHub

## Çfarë realizova

Krijova një pasaportë digjitale për një personazh të sajuar.

- Krijova faqen `index.html`.
- Krijova faqen `rreth.html`.
- Shtova 3 aftësi të personazhit.
- Shtova lidhje vajtje-kthim mes dy faqeve.
- Shtova stilizimin me `style.css`.

## Si hapet

Hap `index.html` në browser.

## Testet

### Testi 1
**Hyrja:** Hapet `index.html`.

**Rezultati i pritur:** Shfaqet pasaporta e Artës.

**Rezultati i marrë:** Faqja hapet dhe shfaqet pasaporta.

### Testi 2
**Hyrja:** Kliko "Rreth Artës".

**Rezultati i pritur:** Hapet `rreth.html`.

**Rezultati i marrë:** Faqja hapet.

### Testi 3
**Hyrja:** Kliko "Kthehu te pasaporta".

**Rezultati i pritur:** Hapet `index.html`.

**Rezultati i marrë:** Faqja hapet.

## Reflektim

Një ndryshim mund të jetë ruajtur lokalisht por ende të mos shihet në GitHub nëse nuk është bërë commit dhe push.
